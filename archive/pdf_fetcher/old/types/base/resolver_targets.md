# Resolver Prototype Targets

These archive files are simple prototype targets for new PDF resolvers.
Each file contains:

- a real DOI-based article URL
- the observed source URL from the diagnostic workbook
- record id
- article title
- a local output directory for ad hoc tests

Current prototype targets:

- `elsevier.py`
- `wiley.py`
- `tandfonline.py`
- `oxford.py`
- `nature.py`
- `cambridge.py`
- `plos.py`
- `akjournals.py`

Existing prototype resolvers already in this folder:

- `frontiers.py`
- `mdpi.py`
- `springernature.py`
