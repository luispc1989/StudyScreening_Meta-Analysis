# PrismaLab Prototype Archive

Archived Next.js prototype for the future master application of `PrismaLab`.

## Run

From the repository root:

```bash
cd archive/apps/prismalab-prototype
npm install
npm run dev
```

## Historical purpose

- test the visual direction of PrismaLab
- organize the workflow by meta-analysis phase
- prepare the transition from tool-first prototypes to a project-first application
- create a natural landing place for a future local SQLite project database

## Status

This folder is archived and no longer the main active frontend.

The active frontend now lives in:

- `apps/prismalab-frontend`
