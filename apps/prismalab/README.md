# PrismaLab

Next.js prototype for the future master application of the Study Screening Toolkit, now named `PrismaLab`.

## Run

From the repository root:

```bash
cd apps/prismalab
npm install
npm run dev
```

## Current purpose

- test the visual direction of PrismaLab
- organize the workflow by meta-analysis phase
- prepare the transition from tool-first prototypes to a project-first application
- create a natural landing place for a future local SQLite project database
