07 — Motion

Animation tokens

All motion is understated. The goal is calm intelligence — nothing should draw attention to itself.

ElementAnimationDurationEasingIntent
Status dot scale(1→.65) + opacity(1→.3) 3s ease-in-out Signals live / active state. Slow cycle reads as calm, not nervous.
Typing dots opacity(.2→.9) 1.5s ease-in-out Staggered 0.25s. Unhurried — Ray is thinking, not loading.
Typing icon static opacity: 0.7 — — Slightly receded vs active message icon — marks the in-progress state.

CSS keyframes

@keyframes sdot-pulse {
  0%, 100% { opacity: 1; transform: scale(1); }
  50%       { opacity: .3; transform: scale(.65); }
}

@keyframes td-blink {
  0%, 80%, 100% { opacity: .2; }
  40%           { opacity: .9; }
}

08 — Rules

Hierarchy rules

These are the decisions that govern Ray's identity. When in doubt, default to less.

Do

Use "Research Assistant" as the descriptor — sentence case, weight 400, 52% opacity. It is context, not branding.

Don't

Use uppercase, tracked, or teal-coloured descriptor text. It competes with Ray's name and reads as a tagline.

Do

Show the descriptor only in the hero card and chat header. Never in message rows or repeated UI.

Don't

Include "PrismaLab" or "AI" in the assistant descriptor. The platform context is already established by the product itself.

Do

Use the sharp top-left corner (border-radius: 4px 12px 12px 12px) on message bubbles. It anchors the bubble to its speaker without a tail.

Don't

Use uniform border-radius on all four corners of the message bubble. It removes the directional anchor and feels generic.

Do

Ensure the icon circle is clearly legible against its background at all three sizes. Dark mode: fill #181D26–#1D2028. Light mode: fill #C8C6BE.

Don't

Use a light circle fill in the light hero card variant. A fill close to the card background makes the icon disappear.
