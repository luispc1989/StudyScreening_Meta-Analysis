# Dissertation Docs

This folder contains dissertation-oriented and cross-project notes that are not
specific to a single app such as `PDF Fetcher`.

Use this folder for:

- dissertation-wide notes;
- cross-application implementation logs;
- writing rules for dissertation documentation;
- final cleanup and delivery checklists.

Current files:

- `DISSERTATION_NOTES.md` - detailed dissertation-oriented notes across the evolving system
- `IMPLEMENTATION_LOG.md` - concise chronological log of cross-project implementation decisions
- `DISSERTATION_NOTES_WRITING_RULES.md` - rules to follow whenever dissertation notes are added or updated
- `FINAL_DELIVERY_CLEANUP_CHECKLIST.md` - checklist of temporary, debug, duplicate, or prototype items to review before final submission
