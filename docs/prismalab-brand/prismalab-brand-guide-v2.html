01 — Brand concept

From evidence to conclusion

PrismaLab is a platform for the full cycle of evidence synthesis — from protocol and literature search to systematic screening, data extraction, quality assessment and statistical meta-analysis.

The name brings together PRISMA, the gold-standard reporting guideline for systematic reviews, and Lab, a space where rigorous, reproducible work happens.

The mark — what it means

The prism

Raw evidence enters as a single beam. The platform provides the structure to decompose it.

The input beam

The literature — unfiltered, unstructured, raw.

The spectrum

A continuous spectrum — not a fixed number of phases. The platform grows without the mark becoming outdated. Colours are decorative.

Important — spectrum colours vs. phase colours

The five colours in the logo mark are decorative. They represent the richness of the synthesis process as a continuous spectrum — not a 1-to-1 mapping to workflow phases. As PrismaLab grows and phases are added or reorganised, the mark does not change. Phase colours in the UI are drawn from the brand palette independently.

02 — The logo

Horizontal lockup

The primary logo is always used in its horizontal form. Three approved variants — one per background tier. Never mix elements from different variants.

06 — Usage rules

Do's and don'ts

08 — Voice & tone

How PrismaLab speaks

Precise, direct, and respectful of the user's expertise — without being cold or overly technical.

Precise, not jargon-heavy

Use correct scientific terminology but never obscure meaning.

"Export your forest plot in SVG or PDF."
"Utilise the arboricultural visualisation module to produce vector-based outputs."
Confident, not arrogant

State capabilities clearly. Don't oversell.

"PrismaLab handles the full review cycle — from protocol to publication."
"The most powerful meta-analysis platform ever built!"
Supportive, not prescriptive

The platform assists — the researcher decides.

"The AI assistant suggests an exclusion reason. You can accept, edit, or dismiss it."
"AI has automatically excluded this study."
Clear, not casual

Professional but human. No startup slang.

"3 studies are pending screening. Continue where you left off."
"Hey! You've got 3 studies waiting — let's knock those out! 🎉"

Writing conventions

Product name

Always PrismaLab — one word, capital P and L. Never "Prismalab", "PRISMALAB", or "Prisma Lab".

AI references

Refer to AI features as "AI assistant" or "AI suggestion" — never "AI decided".

Scientific terms

Use: "systematic review", "meta-analysis", "effect size", "heterogeneity". Spell out on first use in non-expert contexts.

Numbers

Use numerals in UI: "3 studies", "I² = 47%", "p = 0.02". Follow APA style in documentation.

09 — Motion

Animation principles

Motion is functional and restrained. It confirms actions, communicates state changes, and guides attention — never decorates.

Instant

0ms

Toggle, checkbox, radio.

Fast

120ms

Hover effects, button presses, tooltips.

Default

200ms

Dropdown, modal, sidebar expand.

Deliberate

320ms

Page transitions, panel slide.

Emphasis

480ms

Loading screen reveal. Use sparingly.

Easing

ease-out

Default for all transitions. Things decelerate into position.

Loading screen — correct layout

Icon mark and wordmark are a single vertically centred unit. They are not two separate elements. The icon sits directly above the wordmark with 20px gap. The loading indicator sits 20px below the wordmark.

12 — Iconography

Icon style

Phosphor Icons — Regular weight. Clean, scientific, 1.5px stroke system.

Style rules

  • Stroke weight: 1.5px at 24px
  • Corner style: rounded joins and caps
  • Grid: 24x24px base, 2px padding
  • Library: Phosphor Icons (Regular)
  • Colour: inherits from text colour token
  • Never filled unless indicating active state

States

  • Outlined = default / inactive
  • Filled = active / selected
  • Active colour = #5DCAA5
  • Sizes: 16px UI / 20px sidebar / 24px toolbar
  • Touch target: min 44x44px

14 — Monochromatic

One-colour variants

For single-colour contexts — emboss, engraving, stamps, administrative documents, fax, or any reproduction without access to the full palette. Always use an approved mono variant; never desaturate the colour logo yourself.

Positive — black on white

Use: white paper, letterhead, stamps, emboss

Negative — white on black

Use: dark materials, engraving, screen printing on dark

Rule: In mono contexts, "Lab" loses its teal colour and matches the single ink colour. The weight difference (Medium vs Light) still distinguishes the two parts. Never attempt to simulate the colour version by adding a grey tint — use the exact mono files provided.

15 — Accessibility

Contrast & legibility

PrismaLab is a scientific tool used in research workflows. Text must be legible under all lighting conditions. All UI text must meet WCAG 2.1 AA minimum — 4.5:1 for body text, 3:1 for large text (18px+ bold or 24px+ regular).

Non-colour indicators

Never rely on colour alone to convey state. Every colour-coded UI element must have a secondary indicator.

State must also use

  • Icon or symbol (✓ ✕ ⚠)
  • Text label alongside colour badge
  • Pattern or shape change
  • Focus ring on interactive elements (2px, #5DCAA5)
  • Underline for hyperlinks, not colour alone

Minimum sizes

  • Body text: 15px / 400
  • UI labels: 13px / 400 minimum
  • Interactive targets: 44×44px minimum
  • Focus rings: 2px solid, offset 2px
  • Don't use muted (#888780) for critical info

18 — Data visualisation

Statistical output guidelines

PrismaLab produces scientific charts and tables. Visual outputs must be consistent, publication-ready, and accessible. These guidelines define the visual language for all statistical outputs.

Forest plot

The primary output of a meta-analysis. Box = study effect estimate, width of box = weight, horizontal line = confidence interval, diamond = pooled estimate.

Study boxes: #378ADD. Pooled diamond: #1D9E75 (brand teal). CI lines: same as box. Null line: dashed #E0DFDA.

Risk of bias table

Colour-coded domain assessment using Cochrane RoB 2 domains. Never rely on colour alone — always include a symbol.
