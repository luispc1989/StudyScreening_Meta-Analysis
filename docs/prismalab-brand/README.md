# PrismaLab Brand

This folder stores active visual and branding reference material for `PrismaLab`.

Contents:

- `prismalab-brand-guide.html` - active brand guide reference
- `prismalab-brand-guide-v2.html` - later brand guide variant/reference
- `assets/` - logos, icons, loading assets, app icons, favicons, and related visual files
- `tab/` - favicon and browser-tab assets for PrismaLab
- `ray-assistant/` - Ray assistant brand material, treated as part of the broader PrismaLab brand system

Rule:

- PrismaLab-wide visual reference material should live here under `docs/`
- prototype-specific app code should not be the source of truth for shared brand assets
- Ray brand material should also live here, because it is part of the PrismaLab product identity
